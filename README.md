# Lotr Renewed Extended

This is the home of the **Lotr (Renewed) Extended** mod for Minecraft 1.16.5. This mod expands upon the world of Middle-earth, building on the foundation of *LOTR: Renewed*.

---

## Features & Expanded Systems

We have reimplemented and expanded many classic systems, putting our own unique twist and additions into each one:

* **Combat & Factions:** Units, Captains, Conquest, Invasions, and Bandits.
* **World & Exploration:** Structures for Eriador regions, Entity Spawners for structures, Wandering Traders, and Banner Protection.
* **Gameplay & Mechanics:** Traders, the Modifier System, Feast Mode, LOTR Advancements, and Fellowships.

---

## Installation (For Players)
1. Install Minecraft Forge for version 1.16.5.
2. Download the latest `.jar` release of **Lotr Renewed Extended** from [CurseForge](https://legacy.curseforge.com/minecraft/mc-mods/lotr-renewed-extended/) or [Modrinth](https://modrinth.com/mod/lotr-renewed-extended/).
3. Move the downloaded `.jar` file into your Minecraft `mods` folder.
4. Launch the game and enjoy Middle-earth!
